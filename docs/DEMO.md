1. 展示小、中、大尺寸：说明同一活动每天只出现一个标记和一个产品名，没有跳转入口。
2. 在电脑预览点击“刷新真实资讯”：展示已连接 MCP 与查询时间，不显示 Token。
3. 切换野餐格纹、奶油纸笺、奶黄晴天。

5. 切到中秋和春节：布局不变，只变主题与祝福。
6. iPhone 中设置 Token，预览三种尺寸，再展示实际桌面（需要真机验证后录制）。

# 麦麦日历 0.1.0

把今天的小快乐，放在桌面上。

## 安装

下载附件「麦麦日历-iPhone安装包.zip」，解压后将 Scriptable 文件夹内的五个 JavaScript 文件与 MaiCalendarAssets 文件夹拷贝到 iCloud 云盘的 Scriptable 目录。打开 Scriptable，运行麦麦日历，设置自己的麦当劳 MCP Token，随后添加桌面组件。

详细步骤：[iPhone 安装说明](https://github.com/wangsissie561-byte/maimai-calendar/blob/main/docs/INSTALL_IOS.md)。Token 只填写到手机中，不提交到 GitHub。

## 本版内容

- 小、中、大三种 iOS Scriptable 桌面尺寸。
- 奶油纸笺、野餐格纹、奶黄晴天三套日常皮肤。
- 麦当劳 MCP 活动排期，每天展示第一个可识别产品的小图标与摘要。
- 清爽生日贺卡：笑脸餐盒、无蜡烛小蛋糕与「祝你生日快乐！」。
- 春节、中秋插画与 2026—2028 年节日日期。
- 无自动领券、下单或扣积分操作。

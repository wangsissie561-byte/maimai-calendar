# 设计验收基准

2026-10-14 用户确认：以后续第一版小、中、大尺寸真机截图作为规范，由开发方完成后续检查，不重复要求用户截图验收。

- 日常主题保持已验收的信息层级：小尺寸以日期和主插画为核心，中尺寸周历，大尺寸月历；活动仅一个图标和一句摘要，无营销跳转。
- 固定画布为 170×170、360×170、360×380，由 Scriptable 适配系统尺寸。文字和插画必须完整位于画布内，月历覆盖四至六行。
- 生日采用用户确认的奶油白、淡粉圆形与麦麦红黄色，独立贺卡布局。文案固定为“祝你生日快乐！”，允许两行排版；小蛋糕禁止蜡烛。保留笑脸餐盒与生日帽，去掉彩带、礼物堆和密集装饰。
- 大尺寸生日保留完整月份，突出当天；生日优先于其他节日。生日当天活动摘要让位于祝福。
- 后续改动由自动测试、共享绘图计划和程序实际预览检查。电脑验证不能被表述为新增真机覆盖；仅无法独立排除且影响使用的问题需要用户协助。

原始用户截图包含个人桌面内容，不放入公开源码包；公开展示使用项目自身预览图。

# 隐私与安全

- 项目只调用麦当劳官方 MCP 的 `campaign-calendar`，不查询订单、地址、积分或抽奖，不扣款、不领券、不下单。
- iPhone Token 使用 Scriptable Keychain 保存，只发送至 `https://mcp.mcd.cn` 的 Authorization 请求头。项目无共享 Token 或第三方会员后台。
- 生日只保存月日，不要求姓名、年份、手机号；本机设置存入钥匙串，不发送到 MCP。
- 手机缓存仅保存日期、首个产品、图标类别及查询时间，存于本地 library，不写入 iCloud。
- 首次素材从用户安装的本地/iCloud 文件复制到本机，不下载未知脚本，不关闭 HTTPS 校验。
- 电脑预览只监听回环地址，不返回 Token、生日、完整 MCP 响应或用户身份字段；生日/皮肤只保存在浏览器 localStorage。
- 菜单提供删除 Token、清除生日及缓存；浏览器清除站点数据可删除预览偏好。
- 源码、安装 ZIP 和参赛材料不包含真实 Token、会员凭证、聊天记录或他人个人信息。

麦当劳服务自身的数据处理适用其官方协议和隐私政策；Scriptable 钥匙串与 iCloud 的平台行为适用相关平台说明。本项目不声称能改变第三方平台的数据保留规则。
